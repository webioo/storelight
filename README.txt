Storelight by SwpAI
===================

How to use
  Open index.html in Chrome, Edge or Firefox. That's it: no install, no server.
  To publish it, upload this folder to any static host (Netlify, Vercel, GitHub Pages,
  or your own hosting at swpai.in).

What's inside
  index.html                   The whole app (one file). Stock, Sale and Top customers.
  logo/swpai-logo.svg          SwpAI logo, original colours, for light backgrounds.
  logo/swpai-logo-on-dark.svg  SwpAI logo for dark backgrounds.
  logo/storelight-icon.svg     App icon (SwpAI mark on navy).
  logo/storelight-icon-512.png Same icon as a 512x512 PNG.

Good to know
  - Your data is processed in the browser and is never uploaded.
  - The first time the page loads it needs internet once, to fetch the Excel/PDF
    libraries (cdnjs) and the Figtree font (Google Fonts).
  - The logo SVGs are traced from the supplied PNG. If you have the designer's
    original vector file, use that for print or signage.
  - Theme: follows the visitor's device setting; the sidebar button switches it.
  - The intro plays once per browser session. Click or press a key to skip it.
